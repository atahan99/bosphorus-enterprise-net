# Screenshots

| Folder | Contents |
|---|---|
| [`topology/`](topology/) | The final Packet Tracer canvas (`topology-full.png`), the canvas after every build phase in one grid (`build-progression.png`), close-ups of each area (`area-*.png`) and the phase notes |
| [`build/`](build/) | One image per build phase (two for the larger phases), combining that phase's verification captures from [the build guide](../docs/build-guide.md) |
| [`tests/`](tests/) | One image per test from [the test plan](../docs/test-plan.md), with before/after captures side by side |

Command output is rendered from the live device CLI as terminal-style images, with short annotations marking what each line proves; GUI evidence (WLC pages, mail, phone calls) is a screenshot of Packet Tracer itself. Tests checked only by hand or not run have no image; the test plan says which.
