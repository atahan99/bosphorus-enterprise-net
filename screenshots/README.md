# Screenshots

- **Build evidence**, named by phase from [`docs/build-guide.md`](../docs/build-guide.md): `phaseN-topology-full.png` for the whole canvas, `phaseN-topology-partK-<area>.png` for close-ups, plus the phase's verification captures (e.g. `phase8-ephones.png`).
- **Test evidence**, named by test ID from [`docs/test-plan.md`](../docs/test-plan.md) (e.g. `T04-before-edge01.png`, `T04-after-routing.png`).

Command output is rendered from the live device CLI as terminal-style images, with short annotations marking what each line proves; GUI evidence (WLC pages, phone calls) is a screenshot of Packet Tracer itself.
