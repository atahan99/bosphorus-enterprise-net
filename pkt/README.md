# Packet Tracer files

Requires Packet Tracer 9.0.1 (build 9.0.1.0858) or newer.

- `bosphorus-enterprise-net.pkt`: the latest state of the lab.
- `phase-2.pkt` … `phase-9.pkt`, `phase-11.pkt`, `phase-12.pkt`: a checkpoint saved at the end of each build phase (phases 2–9 match Git tag `phase-N`). Phase 0 has its own scratch lab in [`phase0/`](../phase0/); Phases 1 and 10 were documentation only.

After opening a file, follow the reopen checklist in the [build guide](../docs/build-guide.md#phase-9-testing) before running failover tests.
